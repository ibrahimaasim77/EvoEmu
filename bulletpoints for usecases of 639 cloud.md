# Bulletpoints for Use Cases of 639Cloud

- Hosted the EvoEmu dashboard and API on a 639Cloud virtual machine, so teammates and judges could access the demo without running it on their own computers.
- Used the VM to manage optimization runs and save results, including run history and protein sequences.
- Ran demo jobs in the cloud, making it easier to show the full workflow—from submitting a sequence to reviewing the results.
- Used 639Cloud's dedicated compute and storage for a consistent demo environment during the hackathon.

For real BioEmu GPU runs, only say they were hosted on 639Cloud if access to a suitable GPU instance has been confirmed.
